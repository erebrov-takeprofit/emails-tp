TakeProfit — Email Templates

Hand-coded, email-client-safe HTML for TakeProfit's transactional & notification emails. This page is a live index of the built templates, the design system guide, and the master content table.

📋 Notion — email table 📐 Design system guide 💻 GitHub repo

About this project

Each file below is one email template — pure table-based HTML with inline styles, built to render across Apple Mail, iOS, Gmail and Outlook (no flexbox/grid/JS). Images are served from AWS S3 (takeprofit-static.s3.eu-central-1.amazonaws.com), so this repo holds only HTML. Backend fills the {...} placeholders when sending.

The design system guide is the portable spec: tokens, components, footer variants, per-email subjects & preheaders. It's what keeps every email visually consistent.

How it works & how to update

Editing flow

  1. Draft & prompt in the Claude project “Email | Design, texts and coding rules” — the place for wording, subjects and coding rules.
  2. Edit the HTML in the git repo (one file per email). Filenames are kebab-case and mirror the email name.
  3. Log the change — add a dated entry to the Changelog below.
  4. Push to main → Netlify auto-deploys → the preview URLs update.
  5. Update the Notion table — subject, preheader, status, owner, variant, preview URL. Notion is the source of truth for metadata.

Single source of truth

  1. HTML + guide.md → this git repo (canonical).
  2. Email metadata (subjects, triggers, owners, statuses) → Notion table.
  3. Prompting / texts → Claude project. Point it at the repo rather than pasting a static copy, so it always reads the latest guide.
